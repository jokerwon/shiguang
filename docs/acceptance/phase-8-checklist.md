# Phase 8 验收清单：食材资料库与按食材筛选

- **依据**：[ADR-0018](../adr/0018-ingredient-catalog-and-filtering.md#最终共识确认)、[实施清单](../implementation/phase-8-implementation.md)。
- **完整规格**：[GitHub Issue #5](https://github.com/jokerwon/shiguang/issues/5)。
- **状态**：[#6](https://github.com/jokerwon/shiguang/issues/6)（发布并查阅食材资料）已实施并记录证据（见 [phase-8-1-implementation.md](../implementation/phase-8-1-implementation.md)）；其余条目待实施。**勾选表示已有可复核证据，未勾选表示尚未验证或依赖未交付能力。**
- **已确认测试边界**：真实应用外部入口（浏览器、HTTP／AI 工具、导入命令）为主；复用既有 Jest 保留必要行为回归，不新增持久化 e2e／组件测试框架。
- **证据纪律**：记录输入、实际返回／可见状态、运行命令或截图；测试必须验证外部行为，不以 mock 回显、源码文本、私有方法调用次数或固定文案作为通过条件。

| [x] A3 | 更新别名后再读取原菜谱       | 原有稳定关联、用量与必要说明不变；番茄／西红柿为同一身份，鸡蛋／鸭蛋、生抽／老抽仍区分         |
| [x] A4 | 迁移带括号说明与备选原料     | 保留必要说明，人工确认关联，不把“西冷或眼肉”当同时必备，不靠删除括号误归一                     |

## B. 食材内容与发布

| #      | 场景                           | 通过条件                                                                                                   |
| ------ | ------------------------------ | ---------------------------------------------------------------------------------------------------------- |
| [x] B1 | 浏览／搜索列表与详情           | 按名称、别名和单层分类可找到同一发布食材；每种食材一个主要分类，无多级树，无重复身份                       |
| [x] B2 | 发布内容不足或未审核           | 缺名称、审核简介、参考来源或必要审核时不发布空壳；资料可留待审，不伪造数据                                 |
| [x] B3 | 查看完整与部分资料             | 显示真实资料与来源，缺依据的可选段落不展示；图片是当前风格占位图；无菜谱食材仍可查阅，相关菜谱是真实空结果 |
| [x] B4 | 非法／歧义关联经导入或生成发布 | 明确报出问题，不静默猜测身份、不留下残缺发布；全部发布入口经过同样校验                                     |
| [x] B5 | 简介已发布但安全资料不全       | 发布可读资料不被当成已完成安全核查；未知成分不被转换成“确认不含过敏原”                                     |
| [x] B6 | 重复导入、读取发布结果         | 不重复创建身份和关联；核对实际数据库与读取接口结果，而非只验证解析器返回成功                               |

## C. 安全过滤

| #      | 场景                             | 通过条件                                                                                                        |
| ------ | -------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| [ ] C1 | 忌口西红柿、菜谱使用番茄别名     | 正确排除，身份与别名在筛选和安全判断中一致                                                                      |
| [ ] C2 | 大豆过敏、候选食材为豆腐         | 按已核查的成分关系排除，不因食材身份不同绕过；保留已有拦截保护                                                  |
| [ ] C3 | 有过敏设置、加工食品成分无法判断 | 菜谱不进入结果，说明信息不足；全部排除仍为空，不凑数、不引导忽略过敏设置                                        |
| [ ] C4 | 没有过敏设置                     | 可展示满足普通条件的菜谱，但不宣称“过敏安全”                                                                    |
| [ ] C5 | 选中食材与已存安全设置冲突       | 安全优先且明确解释，所选条件不被悄悄清除；食材资料仍可阅读                                                      |
| [ ] C6 | 同数据逐入口查询                 | 普通筛选、相关菜谱、首页 today 和 quick、AI 搜索都不返回相应 blocked 或无法判断的菜谱；不要求各入口排序完全相同 |
| [ ] C7 | 本地条件变化与当前用户设置       | 安全设置来自当前用户的服务端上下文，不因从资料入口清空筛选或客户端传参而丢失；不同用户不串用安全结果            |

## D. 全部包含与查询契约

| #      | 场景                       | 通过条件                                                                       |
| ------ | -------------------------- | ------------------------------------------------------------------------------ |
| [ ] D1 | 食材名称、别名与歧义输入   | 名称／别名定位同一候选，身份明确才筛选；歧义不擅自映射，无效身份不静默扩大查询 |
| [ ] D2 | 同时选择番茄和鸡蛋         | 返回集合每道菜都含两者；仅含一种的菜不返回，含额外食材的菜允许返回             |
| [ ] D3 | 单选、重复别名与无食材条件 | 单选正确，别名不造成重复条件；未选食材时仍可正常使用原有筛选                   |
| [ ] D4 | 选择盐／油并叠加其他条件   | 调味品严格参与全部包含；食材与菜系、标签、时间取交集，无匹配则为空             |
| [ ] D5 | 多页数据含大量安全排除项   | 数据、总数、总页数以同一过滤后集合计算；不先分页再过滤导致漏项、虚高或假空页   |
| [ ] D6 | 请求失败与真实空结果       | 错误明确，不伪装无菜谱；真实空结果不返回相似菜谱补足，不改变排序权重           |

## 验收证据

**2026-09-30（#6，发布并查阅食材资料）**：A1–A5、B1–B6 全部有可复核证据，见 [phase-8-1-implementation.md](../implementation/phase-8-1-implementation.md)（含迁移输出、导入数字、数据库事实核对、真实浏览器走查与自动化检查结果）。

C6/C7（逐入口一致安全）、D 组全部包含与查询契约、E 组 Web 表面、F1–F3（AI 搜索）与 G1–G3 仍未勾选：安全判断与筛选已在真实浏览器核对，但 AI 侧多食材工具契约未交付（#11），Web 交互细节与全库质量门仍需在对应子票内补证据。已交付部分的既有质量门失败（Web lint 4 项、`prompt-input.tsx` 类型错误）均为本次未改动的历史问题，如实记录，不计作本票通过。

> **内容复核状态**：173 条资料由 AI 起草、**维护者已于 2026-09-30 逐条复核**，复核时间写入条目并由导入写库（事实源为 `Ingredient.reviewedAt`，现值为同一时间戳）；无标记条目会被发布闸门拒绝。**来源是复核所用的通用入口页**（USDA FoodData Central / 中国食品安全风险评估中心），尚未逐条替换为具体条目页。
